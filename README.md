# 🎮 Tic-Tac-Toe Game in Python

## 📌 About the Project
This is a simple Tic-Tac-Toe game developed using Python and Tkinter. It allows two players to play the classic X and O game through a graphical user interface (GUI).

## ✨ Features
- Interactive 3×3 game board
- Two-player gameplay (X and O)
- Automatic winner detection
- Draw detection
- Simple and user-friendly interface

## 🛠️ Technologies Used
- **Python**
- **Tkinter** (GUI library)

## ▶️ How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder.
4. Run the Python file:

```bash
python tictactoe.py
```
